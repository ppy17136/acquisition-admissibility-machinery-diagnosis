# Licence map

This repository is a mixed-licence reproducibility release. No single licence
grants reuse rights for every file in the archive.

## Author-created code and documentation: MIT

The MIT License in `LICENSE` applies to author-created source code and release
documentation, including:

- root Python entry points and verification scripts;
- `primary/historical_v1_code/`;
- `cnn/code/`;
- `unified_v2/code/`;
- root documentation and machine-readable release metadata, except where a
  more specific source-data condition is stated below.

The following directories contain source inventories, transformed features,
log-PSD caches, model predictions or numerical evidence derived from the
Paderborn University Bearing DataCenter. They remain subject to the Creative
Commons Attribution-NonCommercial 4.0 International licence and source
attribution requirements:

- `primary/provenance/`;
- `primary/derived/`;
- `primary/evidence/`;
- `cnn/cache/`;
- `cnn/evidence/`;
- `unified_v2/evidence/`.

Official source and licence statement:
https://mb.uni-paderborn.de/kat/forschung/bearing-datacenter

The MIT licence does not override the source-data conditions for the derived
artifacts listed above. Conversely, the CC BY-NC 4.0 conditions do not replace
the MIT licence for the author-created code. Contact the respective rights
holder if a proposed use is not covered by these terms.
