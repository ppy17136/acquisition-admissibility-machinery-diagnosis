# Public data provenance

The included log-PSD cache is derived from the following official public source:

Paderborn University Bearing DataCenter
https://groups.uni-paderborn.de/kat/BearingDataCenter/

Selected bearings: K001-K005, KA04, KA15, KA16, KA22, KA30, KI04, KI14,
KI16, KI18, and KI21. The source dataset is distributed under CC BY-NC 4.0.
This derived package is intended only for non-commercial scientific validation
and retains source attribution. It does not redistribute the raw MAT archives.
